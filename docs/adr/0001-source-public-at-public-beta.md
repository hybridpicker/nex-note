# Source code becomes public with the Public Beta

Nex Note is licensed AGPL-3.0-or-later, and anyone who receives a binary is entitled to its corresponding source. A free public download from a private repository would contradict that, so the repository is made public when the Public Beta launches, and "open source" is part of the website's message. The name, logo, website copy and updater infrastructure stay outside the licence grant (`NOTICE`, `TRADEMARKS.md`).

## Considered Options

- Keep the repository private and send source on request: legally thin and manual for every downloader.
- Switch to a proprietary licence: drops the open-source argument and would need re-licensing of contributions.

## Consequences

Before the repository is made public, its full Git history must be checked for secrets and personal data, because publishing cannot be undone.
