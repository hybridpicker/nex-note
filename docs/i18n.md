# nex-note i18n developer note

The app uses a small internal i18n layer in `lib/i18n.tsx`.

## Add a translation key

1. Add the new key to the English `en` dictionary. This defines the TypeScript key union.
2. Add translations for `de`, `fr`, `es`, and `zh` when the string is user-facing.
3. Use `const { t } = useI18n()` in client components and render `t('your.key')`.
4. Use interpolation with `{name}` placeholders, for example `t('note.setPitch', { step })`.

Missing keys fall back to English. In development, the rendered value is prefixed with `[missing locale:key]` so untranslated UI is visible.

## Add a language

1. Add the locale code to `SUPPORTED_LOCALES`.
2. Add a label to `LOCALE_OPTIONS`.
3. Add a dictionary entry in `dictionaries`.
4. Add the matching manual path in `getManualHref`.
5. Add focused detection, persistence, and UI-switch tests in `test/i18n.test.ts`.

## AI key and missing-tool strings

- `connectAi.*`: the Connect AI panel (`components/ConnectAiPanel.tsx`), including the Browser Preview relay notice `connectAi.browserPreviewNotice` ("Your key and the score you send go through nex-note.com to {provider}. Nothing is stored.").
- `aiKeys.*`: key status and keychain actions in the AI model settings panel.
- `import.missingTool`: shown when an import needs MuseScore 4, Audiveris or Tesseract that is not installed (`{tool}`, `{url}` come from `lib/external-tools.ts`).

These keys have English and German text; French, Spanish and Chinese fall back to English until translated.
